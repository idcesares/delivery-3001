# Telas da turma

Aqui ficam as telas do app Delivery 3001 criadas com IA na **Arena dos métodos** (Aula 11). Cada tela nasceu de um método ágil sorteado: PUA, DSDM, Crystal, ASD, FDD ou LSD.

Nada aqui é obrigatório. Se quiser publicar a sua, crie um arquivo em `telas/` com o seu primeiro nome e o método, por exemplo `telas/ana-dsdm.html`. Quem não quiser mexer no GitHub pode colar o HTML no chat da aula: o professor publica depois.

## Como abrir uma tela

Cada tela é um único arquivo HTML. Baixe o arquivo (botão **Download raw file**) e abra no navegador. Funciona sem instalar nada e sem servidor.
